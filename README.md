# آزمایشگاه علوم هفتم
پروژه اولیه اندرویدی با Python و Kivy برای درس پنجم علوم هفتم.

## ساخت APK با گوشی و GitHub
۱. یک مخزن جدید در GitHub بساز و همه فایل‌های این پروژه، از جمله پوشه مخفی `.github` را بارگذاری کن.
۲. وارد زبانه Actions شو.
۳. گردش‌کار Build Android APK را انتخاب و روی Run workflow بزن.
۴. پس از پایان موفق، از بخش Artifacts فایل `azmayeshgah-oloom-apk` را دانلود کن.
۵. فایل ZIP را باز کن و APK را روی گوشی نصب کن.

## اجرای آزمایشی روی رایانه
`pip install kivy` سپس `python main.py`

## محدودیت مهم
این محیط فایل APK کامپایل نکرده است؛ GitHub Actions باید آن را بسازد. برای نمایش کاملاً درست حروف فارسی در همه دستگاه‌ها، فونت فارسی TTF مانند Vazirmatn باید به پوشه پروژه افزوده و در رابط Kivy تنظیم شود. نمایش فارسی ممکن است با فونت پیش‌فرض بعضی دستگاه‌ها کامل نباشد. محتوا بر اساس متن درخواست تهیه شده و برای تطبیق کلمه‌به‌کلمه با کتاب، باید با صفحه‌های کتاب بررسی شود.
